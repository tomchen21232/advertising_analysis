# Meta 廣告成效儀表板

純前端 HTML 儀表板，讀取 `data/` 資料夾內的 Meta 廣告匯出檔與投手填寫表，自動產生花費分布、療程 × 受眾成本矩陣、漏斗（到診／成交／ROAS）、廣告明細與重點警示。

## 資料夾結構

```
index.html                         儀表板本體
data/meta_ads.xlsx                 Meta 廣告管理員匯出檔（或 meta_ads.csv，二擇一）
data/pitcher_input.xlsx            投手／診所填寫表
templates/pitcher_input_template.xlsx  空白填寫表範本
```

## 每週更新 SOP（約 3 分鐘）

1. Meta 廣告管理員 → 廣告層級 → 選日期區間 → 「報表 → 匯出表格資料」→ 下載 CSV。
   - CSV 不用轉 xlsx，儀表板兩種都能讀。
   - 建議欄位加上「廣告編號」「連結點擊次數」「CTR」；細分選「依時間 → 天」可看趨勢。
2. 檔名改成 `meta_ads.csv`（或 `meta_ads.xlsx`）。只保留其中一個，避免讀到舊檔。
3. GitHub repo → `data/` → **Add file → Upload files** → 拖進去 → Commit changes（同名會覆蓋）。
4. 投手填寫表同樣以 `pitcher_input.xlsx` 上傳到 `data/`。
5. 約 1～2 分鐘後重新整理網頁。

## 投手填寫表（pitcher_input.xlsx）

| 工作表 | 誰填 | 填什麼 |
|---|---|---|
| 廣告補充 | 投手 | 每支廣告的階段、素材類型、投手、素材連結、卡關／下一步（可指定療程） |
| 每週成效回報 | 診所／客服 | 每週 × 分店 × 療程：有效名單、預約、到診、成交、成交金額 |
| 療程對照 | PM | 廣告名稱關鍵字 → 療程，新療程加一列即可 |

Meta 後台已有的數字（花費、曝光、成果…）一律不手填。

## 命名規則

廣告組合名稱：`目標-形式｜分店｜受眾類型｜受眾`，例：`轉換-訊息｜新店｜興趣｜美妝`。
不符合規則的組合會在「資料品質檢查」列出。

## 本機預覽

網頁右上「開啟本機檔案」或直接把檔案拖進頁面，可在不上傳的情況下預覽任何匯出檔。

## 可見範圍

頁面已設定 `noindex`，搜尋引擎不會收錄。但 GitHub Pages 本身沒有登入機制：知道網址的人都能開，公開 repo 內的 `data/` 檔案也能被任何人瀏覽下載。
