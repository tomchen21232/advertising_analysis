# Meta 廣告成效儀表板

純前端 HTML 儀表板：上傳 Meta 廣告匯出檔（＋選填的投手填寫表），自動產生 KPI、廣告花費排行、重點警示、漏斗（到診／成交／ROAS）與廣告明細。

## 使用方式

網頁本身不存放任何廣告資料。每次打開網頁後：

1. Meta 廣告管理員 → 廣告層級 → 選日期區間 → 「報表 → 匯出表格資料」→ 下載 CSV（不用轉 xlsx）。
   - 建議欄位加上「廣告編號」「連結點擊次數」「CTR」；細分選「依時間 → 天」可看趨勢。
2. 打開儀表板網頁，把 CSV 拖進頁面（或按「選擇檔案」）。
3. 投手填寫表 `pitcher_input.xlsx`（選填）可以和 CSV 一起選，範本在 `templates/`。

檔案只在瀏覽器內讀取，不會上傳；重新整理頁面即清除。

> 進階：若之後想讓網頁自動讀檔，把檔案放到 `data/meta_ads.csv`（或 .xlsx）與 `data/pitcher_input.xlsx`，網頁會優先讀取。

## 投手填寫表（pitcher_input.xlsx）

| 工作表 | 誰填 | 填什麼 |
|---|---|---|
| 廣告補充 | 投手 | 每支廣告的階段、素材類型、投手、素材連結、卡關／下一步（可指定療程） |
| 每週成效回報 | 診所／客服 | 每週 × 分店 × 療程：有效名單、預約、到診、成交、成交金額 |
| 療程對照 | PM | 廣告名稱關鍵字 → 療程，新療程加一列即可 |

Meta 後台已有的數字（花費、曝光、成果…）一律不手填。

## 命名規則

廣告組合名稱：`目標-形式｜分店｜受眾類型｜受眾`，例：`轉換-訊息｜新店｜興趣｜美妝`。
不符合規則的組合會在「資料品質檢查」列出。

## 可見範圍

頁面已設定 `noindex`，搜尋引擎不會收錄。但 GitHub Pages 本身沒有登入機制：知道網址的人都能開網頁，但網頁不含任何廣告資料，資料只存在上傳者自己的瀏覽器。
